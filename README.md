# LeadPilot

LeadPilot is an AI-powered assistant designed for artisans and small service businesses to analyze incoming customer requests and help them respond faster.

## What LeadPilot does

When a customer message is submitted, LeadPilot uses AI to:

- Understand the customer's request
- Detect the level of urgency
- Identify missing information
- Summarize the request
- Recommend the next action
- Generate professional response suggestions

The goal is to help small businesses handle incoming leads more efficiently while reducing the time spent analyzing and answering customer messages.

## AI Technology

LeadPilot uses Google's Gemini API to analyze customer requests and generate structured recommendations.

Gemini acts as the intelligence layer of the application, transforming an unstructured customer message into actionable information for the business owner.

## How It Works

1. The user enters a customer request.
2. LeadPilot sends the request to Gemini.
3. The AI analyzes the message.
4. LeadPilot identifies urgency and missing information.
5. The agent recommends the next action.
6. Professional response suggestions are generated for the business.

## Current Status
